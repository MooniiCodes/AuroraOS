# Security Policy

## Supported Versions

| Version     | Supported|
| ------------| ---------|
| Beta 0.1.x  | ✓ |
| Alpha 0.0.x | X |

## Reporting a Vulnerability

To report a vulnerability please contact @DisLoPik on discord. 

## What to Include:

- Version Number (x.x.x)
- What Happend
- What was expected
- How to Reproduce
